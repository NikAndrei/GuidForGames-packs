# GuidForGames — пакеты игр

Данные для приложения-помощника GuidForGames: советы, квесты, секреты и подсказки по играм.
Файлы собираются автоматически из основного репозитория — не правьте их здесь.

Каталог — `index.json`, пакет игры — `<id>.json` (формат описан схемой `GamePack`).

Тексты — пересказ своими словами по открытым гайдам (ссылки на источники — в поле `sources` каждой записи).
Названия игр и персонажей принадлежат их правообладателям.
